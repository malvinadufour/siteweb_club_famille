## Club Famille

#### *Présentation*

Club Famille est une application web développée dans le cadre de mon M1 MIASHS à l'Université Paris 8. <br>
L'objectif du projet était de créer une plateforme permettant de gérer des ateliers et les inscriptions des utilisateurs, avec un espace d'administration et plusieurs fonctionnalités d'accessibilité.

#### *Fonctionnalités*
- Création de compte et authentification
- Inscription et désinscription aux ateliers
- Calendrier des ateliers
- Espace administrateur
- Gestion des utilisateurs et des inscriptions
- Journal d'activité
- Formulaire de contact
- Interface responsive
- Panneau d'accessibilité
- Interface disponible en français et en anglais

#### *Technologies utilisées*
- PHP
- MySQL
- PDO
- HTML
- CSS
- JavaScript

#### *Base de données*
L'application utilise une base de données MySQL permettant notamment de gérer les utilisateurs, les ateliers, les inscriptions et les messages de contact.
